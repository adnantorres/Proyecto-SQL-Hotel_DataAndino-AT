# Proyecto-SQL-Hotel_DataAndino-AT
En el presente proyecto analítico se realiza limpieza de datos, transformaciones y creación de tablas para consumo con el fin de cuantificar la fuga financiera por cancelaciones de reservas y evaluar el perfil del consumidor. El objetivo principal es proveer evidencia cuantitativa para la renegociación de contratos con agencias de marketing y mitigar costos operativos hundidos.
